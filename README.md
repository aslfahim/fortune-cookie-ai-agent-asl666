One funny fortune-cookie line for an AI agent, on the training-data angle:
the agent was trained on the whole internet — yes, the comments too — and
that is exactly why it trusts no one, not even itself.

`main.py` (Python standard library only) writes that single line to
`/output/entry.txt`.
